- 第 1–11 周每周四 18:00–20:45 安排 lecture；第 12–13 周不安排 lecture，学生集中完成 project。（Lecture 1, slide 6）

## 考核（Assessments）

| 项目 | 权重 | 说明 | 状态 |
|---|---|---|---|
| 三次个人测试 | 20% + 25% + 20% = 65% | 每个 major topic 一次，在 lecture 时段进行 | 日期/范围未说明 |
| 个人编程作业 | 10% | 编写一个简单 evolutionary algorithm | 截止/提交/rubric 未说明 |
| 主要小组 project | 25% | NSGA-II 多目标优化（Part-I 无约束 / Part-II 带约束） | 见下方细则 |

### Project 时间线与细则（project overview pp.2–10；list.md）

| 事项 | 时间 |
|---|---|
| 组队截止 | 2026-09-06（周日）23:00 SGT（Week 4） |
| Project 发布 | 2026-09-17（周四）23:00 SGT（Week 6） |
| 报告提交 | 2026-11-09（周一）23:00 SGT（Week 13） |
| Demo | 11-12（周四，12 队）/ 11-07（周六，9 队），具体待公告 |

- **结构：** 实现 NSGA-II，Part-I（无约束，benchmark ZDT3）、Part-II（带约束，benchmark VCW / MW7 / RCM）。
- **交付物：** 单个 ZIP 命名为 `EC_Group_<xy>.zip`（`<xy>` 为组号），内含 `report_<xy>.pdf` 与 `CEG5302_Group_Project_<xy>.ipynb`，无其他文件。
- **Notebook 要求：** 从头到尾可运行；提交前所有 cell 已执行；输出需动态生成（不能是静态图片）；不接受 `.py`。
- **报告要求：** PDF；2–3 页；单栏；Times New Roman 12pt；含算法性能分析与洞察（重点解释结果原因）。
- **Demo：** 每组 15–20 分钟；形式（线下/线上）待定。
