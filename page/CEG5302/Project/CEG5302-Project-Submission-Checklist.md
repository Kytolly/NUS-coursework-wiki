# CEG5302 项目最终交付前检查清单 (Pre-Flight Submission Checklist)

> [!CAUTION]
> **红线警示**：提交不符合格式（如 ZIP 包含多余目录、使用 `.py` 文件、包含静态图片截图、超页等）将直接导致扣分或被系统判定无效。在提交前请由小组成员逐一核对本检查清单。

---

## 检查清单矩阵 (Comprehensive Audit Checklist)

### 1. 打包与命名规范 (Archive & Filename Audit)

- [ ] **ZIP 包命名正确**：严格为 `EC_Group_<xy>.zip`（例如 `EC_Group_12.zip`），无任何额外前缀或后缀。
- [ ] **根目录绝对扁平**：使用终端解压命令检查：
  ```bash
  unzip -l EC_Group_<xy>.zip
  ```
  输出列表**必须且仅有两条记录**：
  - `report_<xy>.pdf`
  - `CEG5302_Group_Project_<xy>.ipynb`
  绝对不允许存在任何子文件夹（如 `EC_Group_12/`）或隐藏系统文件（如 `.DS_Store`、`__MACOSX/`、`.ipynb_checkpoints/`）。

---

### 2. 代码 Notebook 检查 (`CEG5302_Group_Project_<xy>.ipynb`)

- [ ] **无 `.py` 脚本文件**：确保提交的是标准 `.ipynb` 格式文件。
- [ ] **一键完整可运行**：在干净的 Python 环境中执行 `Kernel -> Restart & Run All`，能够从第 1 个单元格顺利执行到末尾，中途无抛出异常报错。
- [ ] **保留完整单元格执行输出**：所有单元格左侧具有连贯递增的执行序号（如 `[1]`, `[2]`, ...），包含全部数字打印与图像渲染。
- [ ] **完全动态生成图表**：所有 Pareto 前沿散点图、IGD 收敛曲线均为 `matplotlib` 或 `seaborn` 动态绘制输出，未内嵌任何 Markdown 静态链接或 Base64 外部图片。
- [ ] **固定随机数种子**：核心算法运行设定了随机种子（如 `np.random.seed(42)`），确保助教复现时输出结果一致。

---

### 3. 学术报告规范 (`report_<xy>.pdf`)

- [ ] **严格篇幅限制**：报告正文长度严格控制在 **2 至 3 页**之间（严禁少于 2 页或超过 3 页）。
- [ ] **排版格式合规**：
  - 单栏排版 (Single column)；
  - 字体：Times New Roman；
  - 正文字号：12 pt；
  - 图表配有清晰的编号、轴标签（Axis Labels）与物理量纲说明。
- [ ] **内容聚焦原因与见解**：不仅展示最终图表，更重点剖析了 NSGA-II 在 ZDT3（不连通前沿）、VCW（3 目标）、MW7（复杂非线性约束）和 RCM（工程约束）上的收敛行为机理。

- [ ] **时长控制**：准备 15 分钟紧凑演讲幻灯片 + 5 分钟自由代码走查与 Q&A 问答。
