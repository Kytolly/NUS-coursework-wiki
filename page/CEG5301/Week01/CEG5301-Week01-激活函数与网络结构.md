# 激活函数与网络结构

## 激活函数（Activation Function）类型

| 类型 | 形式 | 性质 |
|---|---|---|
| 阈值 / 硬限幅 | φ(v) = 1（v ≥ 0）否则 0 | McCulloch–Pitts 1943 使用；**不连续**；不区分放电水平 |
| 分段线性 | 某范围线性、外部饱和 | **连续但不可微** → 算梯度会出问题 |
| Sigmoid / 逻辑 | φ(v) = 1 / (1 + e^{−av})，a 为斜率 | **最常用**；处处连续可微；严格递增；渐近饱和 |
| 双曲正切 | φ(v) = tanh(v) | 输出可为正/负；对真实神经元可能无意义 |
| 高斯（RBF） | φ(v) = e^{−(v−c)²/(2σ²)} | 对真实神经元无生物意义 |

人工神经网络虽源于生物神经元，但已逐渐演化为**纯工程工具**，某些激活函数（如 tanh、高斯）对真实生物神经网络**可能完全无意义**——比如真实神经元只“放正尖峰”，tanh 却允许输出负数。

## 网络结构：信号流图与分层前馈

- **信号流图（signal-flow graph）**：由有向线在节点处互联而成，信号沿箭头方向流动。
- **分层前馈网络**：节点划分为若干**层**；**不允许从较后的层连回较前的层**（严格前馈）；层内连接可能存在。
- **单层前馈网络**：“层数”只数**计算节点组成的输出层**，**输入层的源节点不计**（那里不进行计算）。

## 关键结论：非线性不可或缺

若一个多层前馈网络的所有神经元都工作在其**线性区**，则这个多层网络**等价于一个单层前馈网络**。因此**激活函数的非线性**是神经网络强大的根本原因——没有它，多层网络会退化成单层，无法获得叠加层数带来的表达能力。

> 类比：只靠“放大同一个数”的线性叠加，无论叠多少层都还是一根直线；唯有非线性（如 Sigmoid）才能让每层“弯折”，从而拟合复杂形状。

## Sigmoid 细节与数值示例

Logistic 函数 `φ(v)=1/(1+e^{-av})` 的导数为 `φ'(v)=a·φ(v)(1−φ(v))`。在原点 `v=0` 时 `φ(0)=0.5`，故 `φ'(0)=a×0.5×0.5=a/4`——这正是课件“What is the slope at the origin?”的答案（One 第 49–50 页）。

取 `a=1`：`φ(0)=0.5`、`φ'(0)=0.25`；当 `v→+∞` 时 `φ→1`，`v→−∞` 时 `φ→0`（渐近饱和）。`a` 越大，曲线越陡、非线性越强。

## 激活函数性质对比表

| 函数 | 公式 | 连续 | 可微 | 输出范围 | 备注 |
|---|---|---|---|---|---|
| 阈值/硬限幅 | φ(v)=1（v≥0）否则 0 | 否 | 否 | {0,1} | McCulloch–Pitts 1943 使用（第 47 页） |
| 分段线性 | 某范围线性、外部饱和 | 是 | 否 | 有界 | 梯度计算会遇到困难（第 48 页） |
| Sigmoid/Logistic | 1/(1+e^{-av}) | 是 | 是 | (0,1) | 最常用；严格递增；渐近饱和（第 49 页） |
| 双曲正切 tanh | (e^v−e^{-v})/(e^v+e^{-v}) | 是 | 是 | (-1,1) | 输出可负；真实神经元只放正尖峰（第 51 页） |
| 高斯/RBF | e^{-(v−c)²/(2σ²)} | 是 | 是 | (0,1] | 对真实神经元无生物意义（第 52 页） |
