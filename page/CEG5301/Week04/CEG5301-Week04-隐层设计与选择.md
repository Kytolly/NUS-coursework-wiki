# 隐层设计与选择

> 本页属于：CEG5301 / Week 04
> 前置知识：[[CEG5301-讲义与笔记索引]]
> 预计阅读时间：5 分钟

## 激活函数选择

隐层常见的两种 S 形函数：`logsig(x)=1/(1+e^{-x})`（输出 0..1）与 `tansig(x)=2/(1+e^{-2x})−1`（输出 −1..1）。**推荐 tansig**：某节点的输出是下一层的输入，我们希望其均值落在 0 附近，而不是 (0,1)。

## 隐神经元数与隐层数

常见方法：**试错**、**网络增长**（从小网络加起）、**网络剪枝**（从大网络剪起）。更原则的做法是**几何推理**。

对 1-N-1 MLP，若隐神经元用**分段线性**激活，每个隐神经元产生一个**线段（构建块）**：**最小隐神经元数 ≈ 目标函数基本形状所需的最少线段数**（高维中为超平面数）。光滑函数可先用分段线性逼近；改用 sigmoid 后，二维输入空间的构建块是一块**分段平面**。

**指南**：先估出构建目标函数基本几何形状所需的最少线段/超平面数，作为 1-N-1 MLP 隐神经元数的**首次尝试**。

**示例**：`f(x)=x³+0.3x²−0.4x` 约 3 段 → 1-3-1；`f(x)=0.5sin(πx)−(3/π)x+2−0.1cos(4πx)` 约 9 段 → 1-9-1；二维高斯 `f(x,y)=(2/π)e^{-(x²+2y²)}` 约需 3 个平面 → 2-3-1（logsig），输出层线性时约 2-20-1。

## 为什么需要更多隐层

逼近任意有界连续函数**只需一个隐层**；目标函数可**分解**为子任务时，加层才有优势。“山丘与山谷” `f(x,y)=3e^{-((x-2)²+(y-2)²)}−4e^{-((x+2)²+y²)}`：单隐层 2-30-1 需 121 个权重，双隐层 2-4-2-1 只需 25 个权重，任务被拆成两个高斯丘再线性组合。**隐层数由目标函数被分解的层级数决定**；多数应用单隐层已足够。

## 用 SVD 估计隐神经元数

高维问题很难数清超平面数，可用奇异值分解（SVD）判断隐神经元是否冗余。

矩形矩阵 `H`（N×n）有 `H = U Σ Vᵀ`，`U`、`V` 正交，`Σ` 含递减奇异值 `σ1≥σ2≥…≥σk>0`。**数值秩**＝非零奇异值个数（线性无关列/行数）；**有效秩**＝忽略接近零的小奇异值后的实际独立向量数。例 `A=[[1,0,0],[1,1,0],[1,1,1]]` 的奇异值 `[2.247,0.8019,0.5550]`→有效秩 3；`B=[[1,0,0],[1,1,0],[1,1,0.01]]` 的奇异值 `[2.1358,0.6622,0.0071]`→第三行几乎冗余，有效秩 2。

**剪枝准则**：把 N 个样本输入得到隐层输出矩阵 `H`（N×n），对 `H` 做 SVD；用**相对**大小判断（把奇异值归一化使总和为 1），保留到总量比例 `γ` 的前 k 个；`γ` 常取 95% 或 99%（“多小算小”依问题而定）。

**算法**：① 用足够大的隐神经元数 n 训练到收敛；② 计算所有样本的隐层输出 `H`；③ 对 `H` 做 SVD（Python `numpy.linalg.svd(H)`）；④ 按剪枝准则与阈值得 k（≤n）；⑤ 用 k 个隐神经元**重新训练**缩减网络。

## SVD 剪枝数值示例

对隐层输出矩阵 H 做 SVD，得到归一化后（和为 1）的奇异值如 `[0.70, 0.20, 0.08, 0.02]`：

- 若阈值 `γ=95%`：累计 0.70+0.20+0.08=0.98 ≥ 0.95 → 取 `k=3`；
- 若阈值 `γ=99%`：需累加到 1.00 → 取 `k=4`。

可见“多小算小”主观、依问题而定；γ 常用 95% 或 99%（Four 第 46–48、50 页）。
