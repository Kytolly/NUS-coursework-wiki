# 空间复用与SIR分析

> 本页属于：CEG5104 / Week 03
> 前置知识：[[CEG5104-讲义与笔记索引]]
> 预计阅读时间：6 分钟

## 为什么要空间复用

- **单小区设计**：C 个信道 × s 个时隙 = N = C·s 路通话。位于小区边缘的移动台要得到满意 SNR，需要很大功率，电池耗得快，整体容量也有限。（来源：3_frequency_allocation.pdf 第 15 页。）
- **多小区设计**：把频率在空间上复用（spatial reuse），总呼叫容量按复用因子倍增；但小区边缘用户加大功率会抬高**同频干扰**（co-channel interference）。解决思路是把 FDM 载波分成若干“复用组”，相邻小区分配不同组；若某组内信道太少，中继效率（trunking efficiency）就会下降。核心问题：**同频小区能靠多近？** → 用 SIR 分析。（来源：3_frequency_allocation.pdf 第 16 页。）

## 同频距离的 SIR/SINR 分析

- 直觉：同频距离比 **D/R**（同频小区间距 / 小区半径）越大，同频干扰越小。目标是求出满足目标 SINR 的最小 D/R。
- **最坏情况**：移动台在小区边缘，干扰源是最近的若干个同频小区（共 N_I 个）。

接收端 SINR：

```text
Ψ = P·H / ( N₀W + Σ_{i=1}^{N_I} Pᵢ·Hᵢ )
```

其中噪声功率约 10⁻¹² mW，可忽略。写成 dB 并整理为约束：

```text
Ψ_dB = 10η·log10( (D−R)/R ) − 10·log10( N_I )
10η·log10( D/R − 1 ) > γ + 10·log10( N_I )
```

含义：路径损耗指数 η 越大，干扰随距离衰减越快，同样的 D/R 下 SIR 越高；干扰源数 N_I 越多，需要的 D/R 越大。（来源：3_frequency_allocation.pdf 第 17–18 页。）注意 D 是“同频小区中心间的最小距离”，R 是小区半径，(D−R)/R 正是最坏情况下移动台到最近同频基站的距离与 R 之比；当移动台位于自己小区边缘、正对最近同频基站时干扰最强，因此按最坏情况定 D/R 是保守设计。

| 量 | 含义 | 对 D/R 的影响 |
| --- | --- | --- |
| η（路径损耗指数） | 干扰随距离的衰减快慢 | η 大 ⇒ 同 D/R 下 SIR 高 |
| N_I（同频干扰源数） | 最近同频小区个数 | N_I 大 ⇒ 需更大 D/R |
| γ（目标 SINR） | 目标接收质量门限 | γ 大 ⇒ 需更大 D/R |

## 观察

- 等发射功率下，D/R 与发射功率的具体数值无关。
- 我们只需要 **D/R 这个比值**，不需要绝对 D、R，因此小区可以整体缩放。
- 小区越小，单位面积能服务的呼叫越多（用小蜂窝承载小区域）；代价是跨小区切换（handoff）增多。（来源：3_frequency_allocation.pdf 第 19 页。）

工程含义：SIR 分析把“复用距离”与“目标质量”联系起来——给定目标 SINR γ 与干扰源数 N_I，就能反推出所需的最小 D/R，再据此在六边形簇表里选 N_reuse。若 N_reuse 选得太小，同频干扰超限；选得太大，则每组信道数减少、中继效率（trunking efficiency）下降。因此 D/R 与频谱效率之间存在折中，这正是下一节六边形布局与频谱效率要处理的核心。
