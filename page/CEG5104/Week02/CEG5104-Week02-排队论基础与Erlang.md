# 排队论基础与Erlang

> 本页属于：CEG5104 / Week 02
> 前置知识：[[CEG5104-讲义与笔记索引]]
> 预计阅读时间：8 分钟

**排队论**是随机系统中队列与等待时间的数学分析。排队源于短期需求超过容量（服务时间、到达间隔的随机波动）；若长期需求 > 容量，队列会爆炸。成本/容量折中：总成本 = 服务成本 + 等待成本，存在最优容量。（来源：2_capacity_analysis.pdf 第 40 页附近。）

**排队系统五要素**：呼叫源（有限/无限、同质/异质）、到达过程（关键在到达间隔）、队列配置（单/多队列、位置、balking/reneging、容量有限/无限）、服务机制（单/多并行服务器，服务时间常假设指数分布）、排队规则（FIFO 最常见，还有 LIFO、SPT、EDD 等）。（来源：2_capacity_analysis.pdf 第 42–46 页。）

**记号 A/S/c**：A = 到达间隔分布，S = 服务时间分布，c = 并行服务器数。M = 马尔可夫（指数、无记忆），D = 确定，G = 一般；M/M/c 即指数到达 + 指数服务 + c 台服务器。（来源：2_capacity_analysis.pdf 第 46 页。）

**指数分布** T ~ exp(α)：f = α e^{−αt}，均值 1/α，方差 1/α²。n 个独立指数变量的**最小值**仍是指数，参数为各 α 之和；故 n 个泊松源可合并为 λ = Σλ_i，n 个并行服务器可合并为 μ = Σμ_i。指数到达间隔 ⇔ 泊松到达（无记忆）。（来源：2_capacity_analysis.pdf 第 47–51 页。）

**状态与利用率**：状态 = 系统内顾客数；队长度 = 状态 − 正在服务数；ρ = 设备被使用的期望比例。M/M/1 中 ρ = λ/μ = 容量需求/可用容量；M/M/c 中 ρ = λ/(cμ)。（来源：2_capacity_analysis.pdf 第 52–53 页。）

**生灭过程**：生 = 到达，灭 = 离开。给定系统内有 n 个顾客，下一次到达 T_B ~ exp(λ_n)、剩余服务 T_D ~ exp(μ_n) 且相互独立，每次只发生一次转移 n→n+1 或 n→n−1。

图 1：生灭过程速率图——状态 n 表示系统内有 n 个顾客，状态 n→n+1 的速率为 λ_n，n→n−1 的速率为 μ_n（来源：2_capacity_analysis.pdf 第 55 页；核对 2026-09-07）。

**关键模型**（均为生灭过程稳态）：

| 模型 | 含义 | 稳态/关键结果 | 稳定性 |
| --- | --- | --- | --- |
| **M/M/1** | 单服务器无限等待 | p_n = ρ^n (1−ρ) | 需 ρ<1 |
| **M/M/1/K** | 单服务器、最多 K 个顾客 | p_0 = (1−ρ)/(1−ρ^{K+1})；丢失率 = ρ^K(1−ρ)/(1−ρ^{K+1}) | 即使 ρ≥1 也稳定 |
| **PASTA** | 泊松到达看到时间平均 | 到达者平均 = 时间平均 | 仅泊松成立 |
| **M/M/c** | c 台并行服务器 | n≤c：p_n = (cρ)^n/n!·p₀；n>c：p_n = (λ/μ)^n/(c!·c^{n−c})·p₀ | ρ<1 |
| **M/M/c/c** | c 台、无等待空间（Erlang-B） | p_c = (A^c/c!) / Σ_{i=0}^{c} A^i/i! | 到达全忙即阻塞 |

- **M/M/1**：p_n = ρ^n (1−ρ)，需 ρ<1。
- **M/M/1/K**：最多 K 个顾客，见满即丢弃；p_0 = (1−ρ)/(1−ρ^{K+1})，即使 ρ≥1 也稳定；丢失率 = P{N=K} = ρ^K(1−ρ)/(1−ρ^{K+1})。
- **PASTA**：泊松到达看到的是时间平均。反例：确定性到达 10s、确定性服务 9s 时，到达者看到系统总空（a₁=0），但时间平均 p₁=0.9——顾客平均不等于时间平均，只有泊松成立。
- **M/M/c**：ρ = λ/(cμ)；n≤c 时 p_n = (cρ)^n/n! · p₀，n>c 时 p_n = (λ/μ)^n/(c!·c^{n−c}) · p₀。
- **M/M/c/c**（无等待空间）：到达发现全忙即阻塞，p_c 即 **Erlang-B 公式**，用于电话/电路交换，结论对 M/G/c/c 也成立。
- **Erlang 表**：给定信道数 N 与目标呼损，查表得可承载话务，例如呼损 0.01 时 N=11→5.160、N=12→5.876、N=15→8.108、N=20→12.03 Erl。（来源：2_capacity_analysis.pdf 第 56–61 页。）
