## 主题选择原则

Topic Guide 要我关注“硬件做了什么改变、为什么需要改变、如何评估以及代价是什么”，而不是只介绍应用领域。咨询时建议准备 2–3 个候选主题，由老师协助确定一个方向。

## 建议主题

1. CPU architectural enhancements for ML workloads
2. GPU architectural optimizations
3. Tensor Core architectures
4. Memory hierarchy optimization
5. Cache architecture and cache management
6. SIMD/SIMT architectural improvements
7. Processing-in-Memory (PIM)
8. Near-Memory Computing (NMC)
9. Hardware support for sparse computation
10. AI accelerators integrated with CPUs/GPUs
11. High-Bandwidth Memory (HBM) architectures
12. Multi-GPU architectures and interconnects
13. CPU-GPU heterogeneous computing
14. Vector processors and vector extensions
15. Hardware accelerators for big-data analytics
16. Hardware security for CPUs and GPUs
17. Hardware support for sparse machine learning
18. Chiplet-based AI processors
19. Hardware support for Large Language Models (LLMs)
20. Hardware reliability and fault tolerance
21. Runtime scheduling and resource management for heterogeneous systems

## 选题检查表

- [ ] 论文年份在 2016–2026 内。
- [ ] 论文包含明确的硬件/体系结构创新。
- [ ] 能识别硬件瓶颈和受影响的组件。
- [ ] 有可分析的实验方法和性能指标。
- [ ] 能讨论 energy、area、cost、limitations 和 industrial relevance。
- [ ] 只保留一篇最终论文，并取得必要的 CA1 确认。
